# Bhumika portfolio
Pure HTML, CSS and JavaScript. Open index.html or serve with `python -m http.server 5500` and browse http://localhost:5500. Replace profile in assets/js/config.js; replace remote gallery URLs in gallery.html and hobbies.html with approved local images. Sample content is not verified personal information. Social links are disabled by default; use only guardian-managed public contacts. Do not publish private student details. noindex is not access control. GitHub Pages is public. To deploy, create an empty public repository, push main and select Settings > Pages > Source > GitHub Actions, then run the workflow or push again. The URL is https://YOUR_USERNAME.github.io/bhumika-portfolio/. The workflow checks required pages and JS syntax, not visual rendering.
